# My Favorite Series: Avatar: The Last Airbender

**Avatar: The Last Airbender** is an *animated fantasy* series set in a world where people can control one of the four elements: water, earth, fire, and air.

## Why I Like It
- Amazing story and world-building
- Funny and heartwarming moments
- Strong character development

2. Zuko
3. Uncle Iroh
